# SENSE Online

**みんなの「ふつう」を、数字であそぼう。**

「ちょっと贅沢なランチは、何円から？」のような問いに、自分の感覚を数字で答えるオンライン数値感覚クイズです。ほかの人との感覚の違いを楽しみながら、みんなの真ん中や平均に近い答えを狙います。

## 遊び方

1. 3〜10人でルームに集まります。主催者も回答できます。
2. 出題者が問題を選び、全員が数字で回答します。ほかの人の回答は結果公開まで秘密です。
3. 結果を公開し、正解者に得点が入ります。
4. ラウンドを重ね、合計得点を競います。

### 2つの判定モード

| モード | 正解の決め方 |
| --- | --- |
| 中央値 | 回答の重複を除き、小さい順に並べた真ん中の値。値の種類が偶数なら、大きい側の真ん中を採用します。 |
| 平均値 | 全員の回答の平均値に、最も近い回答をした人。同率の場合は全員が正解です。 |

たとえば中央値モードで回答が `1000・1000・2000・3000` なら、重複を除いた `1000・2000・3000` の真ん中、`2000` が正解です。

初期設定は正解 **+100点**、最大値・最小値は **−50点**。正解に該当する場合は正解の得点が優先され、全員が同じ値の場合は全員正解です。得点やペナルティは変更できます。通常、有効回答が3人未満のラウンドは無得点になります。

## 主な機能

- 社会・生活・定義基準・個人の4ジャンル、合計400問のプリセット問題。
- 各ジャンルから1問ずつ表示する4択の問題候補と引き直し。
- 問題の編集・追加・JSON読み込みができる問題ライブラリ。
- 出題者の順番制・主催者固定・自由指名、主催者による代理出題。
- 回答タイマー、一時停止・延長、追加回答や回答訂正の許可。
- 手動の結果公開と、全員回答後の自動公開。
- ラウンド履歴、ランキング、採点訂正と変更履歴。
- 絵文字リアクション、参加者の管理、BGM・効果音・YouTube再生。
- 1人で開始・採点を確認できるデバッグモード。

## 起動と参加

**主催者の動作環境：Windows 10/11 64bit（x64）、インターネット接続。**

1. [SENSE-Online.zipをダウンロード](https://github.com/UNSUNG4422/sandbox/releases/download/sense-online-2026-10-20/SENSE-Online.zip)し、ZIP全体を展開します。
2. 展開した `SENSE-Online` フォルダ内の `SENSE-Online.exe` をダブルクリックします。
3. 「このPCでゲームサーバーを起動しますか？」で「はい」を選びます。
4. 自動で開くブラウザでルームを作成します。
5. ゲーム画面の「招待リンク」を友達に共有します。
6. 遊び終わったら、サーバーウィンドウの「サーバーを閉じる」またはウィンドウの×で終了します。

元の配付用ZIPは [SENSE Onlineのリリース](https://github.com/UNSUNG4422/sandbox/releases/tag/sense-online-2026-10-20) に収録しています。従来どおりリポジトリを **Code → Download ZIP** から取得しても起動できます。

PythonとCloudflare Tunnel用ツールは同梱しているため、追加インストールやアカウント登録は不要です。参加者はスマホ・PCのブラウザで参加でき、アプリ一式のダウンロードは不要です。

主催PCをスリープ・シャットダウンすると参加者はアクセスできなくなります。ブラウザを閉じるだけではサーバーは終了しません。公開URLは起動中だけ有効で、起動し直すと変わります。

## フォルダ構成

```text
SENSE-Online/
├── README.md          ゲームの紹介と起動方法
├── SENSE-Online.exe   Windows用ランチャー
├── はじめに.txt       元の配付物に含まれる詳しい操作説明
└── system/
    ├── app/          Pythonのゲームサーバー・採点・問題ライブラリ
    ├── static/       ブラウザ画面・BGM・効果音
    ├── python/       同梱Pythonと依存ライブラリ
    ├── cloudflared/  オンライン参加用の接続ツール
    ├── start.ps1     起動処理
    ├── stop.ps1      停止処理
    ├── common.ps1    起動・停止の共通処理
    ├── versions.json 同梱ソフトのバージョン一覧
    └── THIRD-PARTY.txt サードパーティーの情報
```

起動時に作成される `data/`（問題・開催履歴・登録音源）と `.runtime/`（ログ・公開URLなど）はGitの管理対象から除外しています。移動する場合は、終了後に `system` を含むフォルダ一式を移動してください。

詳しい設定・トラブル対処は [はじめに.txt](./はじめに.txt)、同梱ソフトの情報とライセンスの所在は [THIRD-PARTY.txt](./system/THIRD-PARTY.txt) を参照してください。

この紹介は、同梱の `はじめに.txt`、画面内の「遊び方・ルール」、採点処理をもとにまとめています。元の配付物のプログラム・音源・ライセンス文書はそのまま収録しています。
