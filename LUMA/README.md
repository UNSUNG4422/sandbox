# LUMA

**光を、ほどく。**

鏡を回し、光をつなぐパズルゲームです。盤面の鏡やレンズを操作して、すべての星に指定された色の光を届けます。本編40ステージとEXTRA5ステージ、合計45ステージを収録しています。

## ダウンロード・起動

**動作環境：Windows 10 / 11 の64bit版（x64）。**

1. [LUMA-Windows-x64.zipをダウンロード](https://github.com/UNSUNG4422/sandbox/releases/download/luma-v1.0.0/LUMA-Windows-x64.zip)します。
2. ZIPを右クリックし、「すべて展開」を選びます。
3. 展開した `LUMA` フォルダ内の `LUMA.exe` を起動します。

インストール・アカウント登録・インターネット接続は不要です。`LUMA.exe` と同じ場所にあるファイル・フォルダも必要なので、フォルダ一式を保ったまま利用してください。

配付物は [LUMA 1.0.0のリリース](https://github.com/UNSUNG4422/sandbox/releases/tag/luma-v1.0.0) にあります。このリポジトリの **Code → Download ZIP** には、LUMAの実行ファイル・Electronの実行環境は含まれません。

## 遊び方

すべての星に、その星と同じ色の光を届けるとクリアです。青い星には青、桃色の星には桃色、紫の星には両方の光が必要です。

| 仕掛け | 役割 |
| --- | --- |
| 鏡 | 回転させ、光を直角に曲げます。 |
| 浮遊鏡 | 空きマスへ自由に配置できる鏡。離れたマスへも直接移動できます。 |
| 分光器 | 三角の背面から入った光を左右へ分けます。 |
| 色替えレンズ | 通過する光を青または桃色に変えます。 |
| ワープ | 同じ文字のペアへ、光の向きを保ったまま移動させます。 |
| 光のスイッチ | 光を当てている間、同じ数字のゲートを開きます。 |
| 壁・ガラス | 壁は光を止めます。ガラスは光を通しますが、鏡は置けません。 |

全45ステージはステージ選択から自由に選べます。クリア記録と自己ベストが保存されるので、少ない手数でのクリアにも挑戦できます。

## 基本操作

| 操作 | 動作 |
| --- | --- |
| 鏡をクリック / 右クリック | 回転 / 逆回転 |
| 浮遊鏡を選択して空きマスをクリック、またはドラッグ | 鏡を配置 |
| 浮遊鏡をダブルクリック、または回転ボタン | 浮遊鏡を回転 |
| レンズをクリック | 色を切り替え |
| `Z` | 一手戻す |
| `R` | 現在のステージの配置を最初に戻す |
| `Esc` | 選択解除 / メニュー |
| `F11` | 全画面表示を切り替え |

キーボードだけでも操作できます。詳しい操作はゲーム内の「遊び方」を参照してください。

## 自動保存と設定

途中の配置・クリア記録・自己ベスト・設定は自動保存されます。タイトルの「つづきから」で再開できます。「初めから」はステージ1から始め直しますが、クリア記録と自己ベストは残ります。

保存先は `%APPDATA%\LUMA` です。同じWindowsユーザーであれば、ZIPの展開先を変えても記録を引き継ぎます。Web版とは別の保存領域で、Web版の記録は自動では移りません。

設定では効果音・音量・全画面表示・演出・座標表示を変更できます。プレイ記録の消去には確認画面があります。

## 収録内容

このフォルダには、配付用ZIPから取り出したアプリのソースと説明・ライセンス文書を収録しています。元のファイルの内容は変更していません。

```text
LUMA/
├── README.md              ゲームの紹介・起動方法
├── はじめに.txt           元の配付物の操作説明
├── build-info.json        元の配付物のビルド情報
├── LICENSE                Electronのライセンス
├── LICENSES.chromium.html Chromium等のライセンス通知
└── resources/app/
    ├── package.json       アプリの情報
    ├── main.cjs           Electronの起動処理
    ├── preload.cjs        デスクトップ機能との接続
    └── app/               画面・パズル判定・45ステージのデータ
```

Windows版の実行に必要なファイルは、Releasesの元のZIPに一式収録しています。配付物のバージョンは1.0.0で、Electron 44.9.1を同梱しています。`build-info.json` の `sourceCommit` は元の配付物のビルド情報です。

詳しい使い方は [はじめに.txt](./はじめに.txt) を参照してください。この紹介は、同梱の説明書とゲーム内の「遊び方」、ステージデータをもとにまとめています。
