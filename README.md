# sandbox

今までの制作物をまとめて置くリポジトリです。

| 制作物 | 概要 | 動作環境 |
| --- | --- | --- |
| [SENSE Online](./SENSE-Online/) | みんなの「ふつう」を数字で当てる、3〜10人向けオンライン数値感覚クイズ。中央値・平均値の2つのモードで遊べます。 | 主催：Windows 10/11 64bit（x64）、参加：スマホ・PCのブラウザ |
| [LUMA](./LUMA/) | 鏡やレンズで光を導き、すべての星を灯すパズルゲーム。本編40＋EXTRA5の全45ステージ。 | Windows 10/11 64bit（x64）、オフライン対応 |

## LUMAを遊ぶ

1. [LUMA Windows版のダウンロード](https://github.com/UNSUNG4422/sandbox/releases/download/luma-v1.0.0/LUMA-Windows-x64.zip)から配付用ZIPを取得します。
2. ZIP全体を展開し、`LUMA` フォルダ内の `LUMA.exe` を起動します。

インストール・アカウント登録・インターネット接続は不要です。詳しい遊び方は [LUMAの説明](./LUMA/README.md) を参照してください。

LUMAの実行環境一式は [Releases](https://github.com/UNSUNG4422/sandbox/releases/tag/luma-v1.0.0) に収録しています。**Code → Download ZIP** で取得できるのはソース・説明で、LUMAの実行ファイルは含まれません。

## SENSE Onlineを遊ぶ

1. [SENSE Online Windows版のダウンロード](https://github.com/UNSUNG4422/sandbox/releases/download/sense-online-2026-10-20/SENSE-Online.zip)から配付用ZIPを取得し、ZIP全体を展開します。
2. `SENSE-Online` フォルダ内の `SENSE-Online.exe` を起動します。
3. 起動確認で「はい」を選び、自動で開くブラウザでルームを作成します。
4. ゲーム画面の「招待リンク」を友達に共有します。

Pythonなどの追加インストールやCloudflareのアカウント登録は不要です。参加者は招待リンクから遊べます。

詳しいルールや終了方法は [SENSE Onlineの説明](./SENSE-Online/README.md) を参照してください。

SENSE Online単体の配付ZIPは [Releases](https://github.com/UNSUNG4422/sandbox/releases/tag/sense-online-2026-10-20) にあります。従来どおり **Code → Download ZIP** でリポジトリ全体を取得しても起動できます。
